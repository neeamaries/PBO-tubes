# 🍃 FinTrack - Finance Management System

**FinTrack** adalah aplikasi web berbasis Java (JSP & Servlets) yang dirancang untuk membantu pengguna mengelola keuangan pribadi mereka secara efisien. Aplikasi ini memungkinkan pengguna untuk memantau berbagai jenis dompet (Tunai maupun E-Wallet), mencatat riwayat transaksi, serta mengatur anggaran bulanan dengan antarmuka yang modern, responsif, dan dinamis.

Proyek ini dibangun sebagai bagian dari pemenuhan tugas besar mata kuliah Pemrograman Berorientasi Objek.

## 🛠️ Tech Stack
Proyek ini mengadopsi pola arsitektur MVC (Model-View-Controller) secara terstruktur.
* **Frontend:** HTML5, Bootstrap 5, CSS3 Kustom, JavaScript (DOM Manipulation & AJAX Polling).
* **Icons:** [Solar Icons by Iconify](https://icones.js.org/collection/solar).
* **Backend:** Java EE, JSP (JavaServer Pages), Servlets.
* **Database:** Microsoft Azure Database (Cloud) / MySQL.
* **Version Control:** Git & GitHub.
